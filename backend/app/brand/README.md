# Klub brendi rasmlari

Bu papkaga klubning o'z rasmlarini qo'ying (fayl nomlari aynan shunday bo'lsin). Har biri ixtiyoriy:
fayl bo'lmasa, o'sha joy shunchaki chiqmaydi.

| Fayl | Qayerda ishlatiladi | Tavsiya |
|---|---|---|
| `logo-mark.png` | Sertifikat tepasida, hisobot sarlavhasida, tekshirish (QR) sahifasida | Kvadrat, shaffof fon, 1024×1024 |
| `logo-horizontal.png` | Kitobxonlik portfoliosi sarlavhasida | Shaffof fon, eni ≥ 1600 px |
| `seal.png` | Sertifikatda imzo ustidagi pechat | Dumaloq, shaffof fon, 1200×1200 |
| `seal-light.png` | To'q rangli sertifikat dizaynlarida (ixtiyoriy, masalan oltin rang) | 1200×1200, shaffof fon |
| `bot-avatar.png` yoki `.jpg` | Botning Telegram rasmi | Kvadrat, 640×640 yoki kattaroq |
